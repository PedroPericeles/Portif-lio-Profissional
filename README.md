# Portfólio Profissional

## 📌 Sobre o projeto

Website de portfólio profissional desenvolvido para apresentar
minha trajetória, habilidades, projetos, experiências e formas
de contato.

## 🎯 Objetivo

Criar uma interface moderna, responsiva e acessível para
apresentação profissional.

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
- Figma

## 📂 Estrutura do projeto

portfolio/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
├── images/
└── README.md

## 🚀 Como executar

1. Clone o repositório.
2. Entre na pasta do projeto.
3. Abra o arquivo `index.html` no navegador.

## 🎨 Protótipo

Protótipos desenvolvidos no Figma.

## 📋 Funcionalidades

- Navegação entre seções
- Sobre Mim
- Projetos
- Experiências
- Contato
- Layout responsivo
